# WhatsApp Cybernetics

Welcome to the **WhatsApp Cybernetics** repository! This project aims to create a powerful and feature-rich WhatsApp-like application with enhanced functionalities.

## Features

- **Real-time messaging** between users
- **Multimedia support** (images, videos, and audio)
- **Group chat functionality**
- **User authentication**
- **Customizable themes**

## Tech Stack

- **Frontend:** React-Native, Material UI
- **Backend:** Node.js, Express.js
- **Authentication:** JWT
- **Others:** WebSockets for real-time messaging
